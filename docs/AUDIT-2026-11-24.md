# Security and verification addendum — 2026-11-24

## Dependency and signature review

* A fresh RustSec scan found `url` 2.5.8 (RUSTSEC-2026-0592, nested blob URL
  origin stack overflow); the lockfile was upgraded to patched 2.5.9 and its
  compatible `form_urlencoded` 1.2.3. The updated graph passed cargo-audit and
  cargo-deny in [run 45528002486](https://github.com/SeanShaffer88/ytTrayDL/actions/runs/45528002486).
  Six informational unmaintained/unsound notices remain; reachability and
  remediation tracking are in [DEPENDENCIES.md](DEPENDENCIES.md). No
  vulnerabilities are ignored by the policy.
* yt-dlp's detached signed SHA-256 list is now required and checked against the
  pinned RSA release key before activation, in addition to size and API digest
  checks. Offline tests use the unmodified public 2026.11.23 release signature
  and checksum list, plus altered/missing/truncated inputs and rollback checks.
  The pinned key originated in upstream's GitHub repository, not an independent
  out-of-band verification. The intentionally restricted OpenPGP format, key
  rotation/revocation limits, and ffmpeg's remaining metadata trust are in the
  [security policy](../SECURITY.md).
* The `ring` verifier and its new transitive dependency license texts are retained
  in [THIRD-PARTY-NOTICES.txt](../THIRD-PARTY-NOTICES.txt). This addition does
  not expand that file into an exhaustive legal inventory of all dependencies.

## Evidence and limits

[CI run 45527017474](https://github.com/SeanShaffer88/ytTrayDL/actions/runs/45527017474)
on commit `7a4aab2` passed Linux format/clippy/tests, Windows-native all-feature
clippy/check/tests, MSRV checks on both platforms, media-field validation and
all installer scenarios including real managed tool provisioning. The 60-second
URL and clipboard fuzz smoke runs passed on `52e20d1` in
[run 45527041363](https://github.com/SeanShaffer88/ytTrayDL/actions/runs/45527041363).
A follow-up added signature-parser fuzzing seeded with a real public signature
and malformed variants; all three 60-second fuzz smokes passed in
[run 45530227620](https://github.com/SeanShaffer88/ytTrayDL/actions/runs/45530227620).
Later commits added signature-failure rollback and untrusted-sidecar metadata
regressions. See the PR checks for the final commit rather than treating earlier
results as proof for it. Unit and native fake-downloader tests are offline. Dedicated
installer and media field jobs deliberately use network access.

The first Windows signed-fixture test exposed line-ending conversion; the
fixture is now marked byte-preserving in `.gitattributes`. The Linux cross-target
clippy job could not compile `ring` without an MSVC linker/SDK, so the same
Windows all-feature and field-harness checks now run with real MSVC on the
Windows runner instead. A separate earlier real-media job failed without an
accessible diagnostic log; a subsequent run passed. CI cannot establish
interactive desktop focus, DPI, hotkey, accessibility or GPU behavior on real
Windows installations; see [WINDOWS-SAFETY.md](WINDOWS-SAFETY.md).
